# Glossary

- **AEO:** Answer Engine Optimization; answer-oriented visibility work.
- **AI Visibility:** The repository's GEO/AEO/SEO scanning and improvement system.
- **Brand DNA:** Workspace-scoped brand identity and guidance used by AI flows.
- **GEO:** Generative Engine Optimization; visibility in AI-generated answers.
- **RLS:** PostgreSQL Row Level Security, used to enforce workspace data access.
- **SDR:** External Social Distribution Engine used by the server-side publishing proxy.
- **SocialAPI:** An alternate distribution provider selected by configuration.
- **Workspace:** The tenant boundary for identity, content, data, usage, and permissions.
- **Server function:** A server-only function exposed through the RPC transport.
- **Route kernel:** `defineRoute`, the shared auth/validation/authorization/rate-limit wrapper.
- **Finding:** A persisted GEO issue with a stable rule/fingerprint lifecycle.
- **Verification scan:** The scan that confirms whether a finding is resolved.
- **Lease:** A time-bounded worker claim on a background job row.
- **Gateway:** A server adapter that centralizes provider calls and controls.
- **Raval AI:** Historical repository/documentation name; use Mellox AI for current product terminology unless quoting history.
